# NetPath 1.5 - Field lab

Open Field lab from the sidebar, or visit http://127.0.0.1:4173/#field after starting NetPath.

Three independent jobs share an office topology: incorrect default gateway, wrong access VLAN, and an access policy denying the server. Select devices to inspect and configure them. Run checks through console commands or shortcut buttons. The trace shows the simulated forwarding path and failure point; a packet marker travels along that path when motion is enabled.

Each job saves its configuration, recent console output, reachability checks and completion in the local database and ordinary backups. Applying a configuration clears the old checks and reopens the job. Both printer and server must respond before it can be closed. These records do not award lessons or certificates automatically.

This is a bounded training model: fixed IPv4 endpoints, working physical links, an access VLAN, fixed connected routes and a simple inbound IP policy. It does not simulate full IOS, ARP timing, spanning tree, wireless, DNS or application health. Supported commands are listed by help. A successful server ping verifies IP reachability, not web application behavior. Live Packet Tracer and online integrations remain deferred.

The classroom navigation is replaced with a return link while in the field workspace. Device selection and commands work with keyboard controls. Narrow screens stack the inspector and allow scrolling the topology; reduced-motion settings disable the packet marker.

The previously requested final readiness exam is included and tested: all 37 lessons and passing Challenge attempts in all seven tracks unlock a 60-question final exam, covering every current lesson. Requirements: 90% overall, 80% per tested domain, 5 of 6 constructed responses; optional 90-minute timer. The resulting NetPath CCNA Readiness certificate is an independent learning achievement, not Cisco certification or a pass guarantee.

Verification: 32 automated tests pass, including save/restart behavior, invalid field saves, fault-specific forwarding, final-exam prerequisites and lesson coverage. Browser tests completed all three jobs and confirmed saved progress after reload using a separate QA database.

Restart the existing server, then refresh your browser to load this release. The ZIP contains program files only. Preserve your existing data folder when updating and export a backup first. No learner data was copied into the ZIP or replaced during installation.
