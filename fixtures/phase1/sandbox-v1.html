Supported behavior and limits

Editable Ethernet topology; copper auto-MDI-X and fiber ports; link power and interface state; access VLAN switching; static IPv4 addresses and host gateways; connected and static routes selected by longest prefix; ARP request/reply and cache expiry; source MAC learning and forwarding; echo request and return-path checks. Maximum 50 devices and 100 cables.

This is a bounded educational model, not a full IOS emulator. VLAN trunks, STP convergence, DHCP, DNS, NAT, ACLs, OSPF, IPv6, wireless, and real traffic timing are not simulated here. Switch loops are bounded during traversal; STP is not modeled. TTL decreases at forwarding routers; hosts and switches do not decrement it. Learned tables reset when the topology changes or this page reloads. Addresses use /1–/30; equal-prefix routes use configuration order.
