# NetPath 1.3 - specialist tracks and certificate exports

The curriculum now includes 37 lessons and 181 original questions. Four new 45-minute specialist workshops cover address-plan auditing, segmented switching investigations, route/return-path diagnosis, and access-policy test matrices. Each includes a worked example, independent exercise, simplified reading, and ten questions across the lesson and practice bank.

Seven certificate tracks are available: Network Foundations Practitioner, Network Operations Practitioner, Comprehensive Networking Practitioner, IPv4 Addressing Specialist, LAN Switching Specialist, IP Routing Specialist, and Network Security Specialist. Specialist exams draw multiple-choice questions from their own course module and use topic-specific constructed responses. Every track offers Core, Applied, and Challenge difficulty with the existing passing requirements. These are NetPath tracks, not additional official CCNA domains.

Certificates use a cream, navy and gold landscape layout with a NetPath seal, learner name, track, difficulty, score, timing mode, issue date and credential ID. Earned records keep their original IDs. The preview gallery contains 42 watermarked combinations. PNG and PDF buttons work both for previews and earned certificates. Earned downloads remain available only after a passing completed attempt.

PNG files are 2400 by 1700 pixels. PDFs contain that high-resolution certificate image on one landscape A4 page; text is not selectable or tagged. SVG remains available for scalable artwork. Export runs locally in the browser without an external conversion service or extra runtime installation.

Validation: 27 automated tests pass. Browser checks verified seven exam choices, changing sample difficulty/timing, and PNG/PDF downloads. The final downloaded PDF was rendered with Poppler and visually checked for spacing, clipping and typography. Tests use isolated databases. Learner data was not replaced.

To load this update, close the old NetPath server window, run Run NetPath (keep open).cmd, and refresh the browser. When updating another installation from the ZIP, preserve its data directory and export a backup first.

## Future scope

AWS cloud engineering is a future expansion, not included in this release. Plan its foundations, IAM, VPC networking, compute, storage, observability and cost-controlled labs separately before implementation. Online features and live Packet Tracer integration remain deferred. No cloud account or online service was activated.
